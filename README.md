# Essential Hub
A grocery delivery project built with Kotlin, Jetpack Compose and Firebase. This is a learning project. Payments will be used in test (sandbox) mode only.

## What is inside
- UserEssentialHub: customer app. Customers browse products, add to cart, enter address, and place an order. This is the app where payments will be accepted.
- AdminEssentialHub: seller app. Admins add products and manage their own orders.
- backend: Firebase Cloud Functions (notifications).
